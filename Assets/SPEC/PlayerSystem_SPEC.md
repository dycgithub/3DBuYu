# 玩家系统 (Player System) 规格说明书

## 模块概述

玩家在 3DBuYu 中操控的是一台**附着在球体表面的炮台**。炮台本身**不受伤害、不死亡**——玩家系统不需要生命值管理。原 `PlayerHealth` 类保留，供其他需要生命值管理的实体使用（如敌人护盾、未来可能的多人模式等）。

## 玩家能力

| 能力 | 说明 |
|------|------|
| **球面移动** | WASD 键在球体表面滑行 |
| **自动攻击** | 炮台自动索敌并开火 |
| **子弹切换** | 1-5 数字键切换已解锁子弹 |
| **商店访问** | Tab 键打开商店（游戏不暂停） |

## 玩家属性

| 属性 | 来源 |
|------|------|
| 移动速度 | 炮台组件 (`SurfaceMovement.moveSpeed`) |
| 当前子弹 | 炮台组件 (`Turret`) |
| 已解锁子弹 | `SaveSystem` 永久记录 |
| 升级等级 | `SaveSystem` 永久记录 |

## 不需要的系统

- ❌ 生命值（炮台不受伤害）
- ❌ 死亡/复活
- ❌ 无敌帧
- ❌ 治疗机制

## 保留组件 (PlayerHealth.cs)

`PlayerHealth.cs` 类作为**通用生命值管理组件**保留在代码中，功能包括：
- 伤害处理（减伤、暴击）
- 治疗机制（立即/持续）
- 无敌系统（受伤后无敌帧）
- 死亡/复活回调

该组件可用于：
1. 敌人 BOSS 的特殊护盾层
2. 未来可能的多人合作模式
3. 可破坏的障碍物

## 依赖关系

```
Player (Turret)
├── SurfaceMovement (球面移动)
├── Turret (自动索敌+射击)
└── ScoreManager (分数管理)
```

## 测试要点

1. **功能测试**: 移动+射击同时进行、子弹切换响应
2. **性能测试**: 长时间游戏内存表现
3. **集成测试**: 与 ScoreManager、商店UI联动

---

*对齐 GDD v3.0: 玩家=炮台, 无生命值, 不死亡*
