## 1. 游戏概述

### 1.1 核心概念
3DBuYu 是一款**3D球面塔防射击游戏**。玩家控制炮台在一个球形世界上移动，自动攻击范围内的敌人，通过攻击敌人获得积分,升级子弹的穿透力,伤害,效果,大小,跟踪强度和炮台的移速,射速,每次设计子弹数量,索敌范围
在积分到达一点分数后会扩大球的半径,玩家可以在更大范围移动,可以攻击更多怪物

### 1.2 核心循环
```
在球面移动 → 发现敌人 → 自动瞄准攻击 → 击杀怪物 → 升级炮台 → 应对更强敌人 → 积分获取成就 → 范围扩大
```

### 1.3 独特卖点
- **球面移动**: 独特的球面坐标移动系统，玩家可在3D球体表面自由移动
- **自动战斗**: 炮台自动搜索并攻击最近敌人，玩家专注走位和策略
- **深度升级**: 多层级炮台升级系统，支持自定义子弹配置
- **性能优化**: 对象池系统确保流畅的弹幕体验

## 2. 游戏系统架构

### 2.1 系统概览

游戏采用**模块化架构**，各系统通过事件驱动进行通信，实现低耦合高内聚。

```
┌─────────────────────────────────────────────────────────────┐
│                     GameManager (核心控制器)                  │
│   状态管理 | 流程控制 | 难度调节 | 存档管理                      │
└─────────────────────────────────────────────────────────────┘
         │              │              │              │
    ┌────▼────┐    ┌────▼────┐    ┌────▼────┐    ┌────▼────┐
    │  炮台   │    │  敌人   │    │  资源   │    │  特效   │
    │  系统   │    │  系统   │    │  系统   │    │  系统   │
    └─────────┘    └─────────┘    └─────────┘    └─────────┘
         │              │              │              │
    ┌────▼────┐    ┌────▼────┐    ┌────▼────┐    ┌────▼────┐
    │  子弹   │    │  玩家   │    │  掉落   │    │  音频   │
    │  系统   │    │  系统   │    │  系统   │    │  系统   │
    └─────────┘    └─────────┘    └─────────┘    └─────────┘
```

### 2.2 命名空间组织

| 命名空间 | 职责 |
|---------|------|
| `TurretSystem` | 炮台控制、升级、配置 |
| `BulletSystem` | 子弹飞行、碰撞、穿透 |
| `EnemySystem` | 敌人AI、状态机、生成管理 |
| `SphereMovement` | 球面移动、坐标转换 |
| `PlayerSystem` | 玩家血量、状态 |
| `GameSystem` | 游戏流程、资源、存档 |
| `EffectSystem` | 视觉特效管理 |
| `Utils` | 通用工具类（对象池等） |

## 3. 炮台系统 (TurretSystem)

### 3.1 核心职责

- **自动索敌**: 搜索范围内最近的敌人并锁定
- **瞄准射击**: 平滑旋转朝向目标，按射速发射子弹
- **升级强化**: 通过 `TurretLevelData` 实现多级升级

### 3.2 炮台属性

| 属性 | 说明 | 升级影响 |
|------|------|---------|
| `damage` | 单发伤害 | 等级提升增加 |
| `range` | 索敌范围 | 扩大攻击覆盖 |
| `fireRate` | 攻击间隔 | 降低间隔提高DPS |
| `bulletSpeed` | 子弹速度 | 提高命中率 |

### 3.3 升级链设计

```
Level 1 (初始) → Level 2 → Level 3 → ... → Level N (顶级)
     │              │           │
     ▼              ▼           ▼
  基础属性      +20%伤害    +50%范围
              +10%范围     -30%射速
```

**升级条件**: 消耗金币/经验，检查 `nextLevel` 是否存在

### 3.4 设计要点

- **对象池**: 子弹使用 `ObjectPool<Bullet>` 预热和复用
- **降级策略**: 对象池失效时自动使用 `Instantiate`
- **特效联动**: 攻击/升级时调用 `EffectManager` 播放特效

## 4. 子弹系统 (BulletSystem)

### 4.1 核心职责

- **飞行控制**: 支持直线飞行和追踪模式
- **碰撞处理**: 检测敌人/墙壁，造成伤害
- **穿透机制**: 支持多次穿透后销毁

### 4.2 子弹配置 (BulletConfig)

| 参数 | 类型 | 说明 |
|------|------|------|
| `speed` | float | 飞行速度 |
| `isHoming` | bool | 是否追踪目标 |
| `penetrationCount` | int | 穿透次数 (0=击中即销毁) |
| `ignoreWalls` | bool | 是否穿透墙壁 |
| `maxDistance` | float | 最大飞行距离 |
| `bulletColor` | Color | 子弹颜色 |
| `hitEffectPrefab` | GameObject | 击中特效 |

### 4.3 子弹类型规划

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **普通弹** | 直线飞行，无穿透 | 初期炮台 |
| **追踪弹** | 自动追踪目标 | 高级炮台 |
| **穿甲弹** | 多次穿透 | 清群怪 |
| **霰弹** | 多发散射 | 近距离高伤害 |

### 4.4 对象池集成

```csharp
// 预热数量
bulletPrewarmCount = 10
// 最大容量
poolMaxSize = 50
// 自动回收
maxDistance = 50f 或 timeout = 5s
```

## 5. 敌人系统 (EnemySystem)

### 5.1 敌人类型

| 类型 | 特点 | 数值倾向 |
|------|------|---------|
| **Normal** | 平衡型，标准行为 | 血量/速度/伤害均衡 |
| **Fast** | 高速低血量 | 速度×2，血量×0.5 |
| **Tank** | 高血量低速 | 血量×3，速度×0.5 |
| **Flying** | 飞行单位，无视地形 | 血量×0.7，可跨越障碍 |

### 5.2 状态机设计

```
┌───────┐    检测到玩家    ┌───────┐    进入攻击范围    ┌───────┐
│ Idle  │ ───────────────▶│ Chase │ ───────────────▶ │Attack │
└───────┘                 └───────┘                   └───────┘
     │                         │                          │
     │ 丢失目标                │ 离开攻击范围              │ 死亡
     ▼                         ▼                          ▼
┌───────┐                 ┌───────┐                ┌───────┐
│Patrol │                 │ Chase │                │ Dead  │
└───────┘                 └───────┘                └───────┘
```

### 5.3 敌人属性

| 属性 | 说明 |
|------|------|
| `maxHealth` | 最大生命值 |
| `moveSpeed` | 移动速度 |
| `attackDamage` | 攻击伤害 |
| `attackRange` | 攻击范围 |
| `detectionRange` | 检测玩家范围 |
| `coinDropAmount` | 金币掉落 |
| `experienceValue` | 经验值 |

### 5.4 波次生成 (EnemySpawnManager)

**波次配置结构**:
- `preparationTime`: 波次准备时间
- `enemies[]`: 敌人配置列表
  - `enemyType`: 敌人类型
  - `spawnCount`: 生成数量
  - `spawnInterval`: 生成间隔
  - `delayStart`: 延迟开始
- `healthMultiplier`: 血量倍率（难度递增）

**生成策略**:
- 安全距离检测：玩家附近不生成
- 多生成点支持：分散生成位置
- 循环模式：可选无限波次

## 6. 球面移动系统 (SphereMovement)

### 6.1 核心概念

玩家在**球体表面**移动，使用球坐标系（经度/纬度）控制位置。

**坐标转换**:
- 输入: 水平键 → 经度变化（沿纬线移动）
- 输入: 垂直键 → 纬度变化（沿经线移动）

### 6.2 移动特性

| 特性 | 实现 |
|------|------|
| **朝向球心** | 物体始终面朝球心方向 |
| **极点处理** | 80°以上使用平滑过渡避免万向锁 |
| **平滑移动** | `SmoothDamp` 实现惯性效果 |

### 6.3 相机跟随 (SphereCameraController)

- 跟随玩家在球面移动
- 保持与球心的距离
- 平滑过渡避免抖动

### 6.4 范围扩展机制

**核心玩法**: 积分达到阈值 → 扩大球半径 → 更大活动范围

```
初始半径 r₀ → 积分 S₁ → 半径 r₁ = r₀ × 1.5
                     → 积分 S₂ → 半径 r₂ = r₁ × 1.3
```

## 7. 玩家系统 (PlayerSystem)

### 7.1 生命值系统 (PlayerHealth)

**核心属性**:
- `maxHealth`: 最大生命值
- `invincibilityTime`: 受伤后无敌时间
- `healthRegenPerSecond`: 自然回血速度

**受伤机制**:
1. 检查无敌状态
2. 扣除血量，触发闪烁效果
3. 启动无敌时间
4. 血量归零 → 死亡

**复活机制**:
- 指定复活位置
- 可选恢复血量
- 复活后短暂无敌

### 7.2 事件系统

| 事件 | 触发时机 |
|------|---------|
| `OnHealthChanged` | 血量变化 |
| `OnDamageTaken` | 受到伤害 |
| `OnHealed` | 受到治疗 |
| `OnDeath` | 死亡 |
| `OnRespawn` | 复活 |

## 9. 掉落系统 (GameSystem.DropManager)

### 9.1 掉落类型

| 类型 | 效果 | 视觉表现 |
|------|------|---------|
| **Coin** | 增加金币 | 金色圆形 |
| **Experience** | 增加经验 | 蓝色光球 |
| **HealthPack** | 恢复生命 | 绿色十字 |
| **PowerUp** | 临时强化 | 紫色星形 |
| **Gem** | 稀有货币 | 钻石形状 |

### 9.2 掉落机制

**生成规则**:
- 位置: 敌人死亡位置 + 随机偏移
- 弹出: 初始向上弹起
- 权重: 按配置权重随机选择

**拾取机制**:
- 磁力吸附: 玩家进入范围自动吸引
- 消失: 超时消失，消失前闪烁提示

### 9.3 掉落数量规则

| 金币数量 | 生成方式 |
|---------|---------|
| ≤10 | 单个掉落 |
| 11-50 | 分成3-5个 |
| >50 | 大量散落 (最多10个) |

## 10. 游戏管理系统 (GameSystem.GameManager)

### 10.1 游戏状态

```
Menu → Playing ⇄ Paused → GameOver / Victory
```

| 状态 | 说明 |
|------|------|
| `Menu` | 主菜单 |
| `Playing` | 游戏进行中 |
| `Paused` | 暂停 (ESC切换) |
| `GameOver` | 玩家死亡 |
| `Victory` | 通关胜利 |

### 10.2 难度系统

| 难度 | 倍率 | 特点 |
|------|------|------|
| Easy | 0.7× | 敌人血量减少 |
| Normal | 1.0× | 标准体验 |
| Hard | 1.5× | 敌人血量增加 |
| Nightmare | 2.5× | 极限挑战 |

### 10.3 存档数据

```csharp
GameSaveData {
    totalPlayTime,      // 总游戏时长
    wavesCompleted,     // 完成波次
    difficulty,         // 当前难度
    lastPlayDate        // 最后游玩日期
}
```
