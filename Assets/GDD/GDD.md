# 3DBuYu (3D捕鱼) 游戏设计文档

**版本**: 2.0
**日期**: 2026-05-06
**引擎**: Unity 2022.3.13f1c1 (LTS)
**渲染管线**: URP 14.0.9

---

## 1. 游戏概述

### 1.1 核心概念

3DBuYu 是一款**环形竞技场射击游戏**。玩家控制一门炮台在圆形轨道上移动，自动瞄准并攻击场内四处游动的怪物鱼群。炮台本身不会被攻击——玩家的挑战在于射击技巧、走位策略和资源管理，不断扩展竞技场并购买更强子弹。

### 1.2 一句话描述

> 站在不断扩大的环形轨道上，自动瞄准击杀鱼群，用积分换取更强的子弹。

### 1.3 独特卖点

- **环形轨道移动**: 炮台在圆形轨道上自由滑动，玩家专注走位和瞄准方向
- **鱼群敌人**: 使用 boids 算法的怪物鱼群，产生自然的聚集、分离、巡游行为
- **自动射击**: 炮台自动索敌开火，玩家专注移动和升级决策
- **渐进扩展**: 积分达到阈值 → 轨道半径扩大 → 敌人变强 → 解锁更强子弹
- **积分商店**: 所有升级用击杀积分购买，无付费设计

### 1.4 核心游戏循环

```
移动炮台(环形轨道)
    │
    ▼
自动索敌 → 射击鱼群 → 击杀得分
    │                      │
    │                      ▼
    │              积分购买子弹升级
    │                      │
    │                      ▼
    │              分数达到阈值
    │                      │
    ▼                      ▼
轨道半径扩大 ←── 怪物变强、种类增加
```

### 1.5 游戏结束条件

- **无死亡/失败机制**（炮台不受伤害）
- 游戏为**无限循环**，追求高分
- 未来可加入"时间限制生存模式"或"BOSS击败胜利条件"

## 2. 竞技场设计

### 2.1 基本结构

```
          ┌─────────────────────┐
          │    怪物鱼群活动区    │
          │    (环形内部)        │
          │                     │
          │    ╭─────────╮      │
          │    │ 玩家轨道 │      │  ← 炮台在此轨道上移动
          │    │  (圆环)  │      │
          │    ╰─────────╯      │
          │                     │
          │   鱼群自由游动       │
          └─────────────────────┘
```

### 2.2 轨道参数

| 参数 | 初始值 | 说明 |
|------|--------|------|
| `orbitRadius` | 10.0 | 轨道半径（单位） |
| `orbitHeight` | 0.0 | 轨道高度（Y轴偏移） |
| `minRadius` | 5.0 | 最小轨道半径 |
| `maxRadius` | 50.0 | 最大轨道半径 |

### 2.3 轨道扩展

轨道是炮台移动的**唯一路径**。半径随分数增长：

| 分数阈值 | 轨道半径 | 说明 |
|----------|----------|------|
| 0 (初始) | 10 | 小圈，鱼群密度高 |
| 500 | 15 | 鱼群空间变大 |
| 1500 | 22 | 鱼种类增加 |
| 3500 | 30 | 出现快速鱼 |
| 7000 | 40 | 出现坦克鱼 |
| 12000 | 50 (最大) | 所有鱼种混出 |

扩展曲线: `radius = minRadius + (maxRadius - minRadius) * (1 - e^(-score / 3000))`

### 2.4 怪物活动区域

- 鱼群在**轨道内部 + 外部周边**游动（活动半径 = 轨道半径 × 1.5）
- 鱼群使用 boids 算法产生自然群游行为
- 鱼群会接近轨道但不穿过（在轨道半径 ±2 的环带区域内移向轨道中心方向）

## 3. 炮台系统

### 3.1 基本机制

炮台是玩家的唯一操控对象，不受伤害，不死亡。

| 操作 | 按键 | 说明 |
|------|------|------|
| 顺时针移动 | D / → | 沿轨道顺时针滑动 |
| 逆时针移动 | A / ← | 沿轨道逆时针滑动 |
| 固定位置 | 不按键 | 炮台停在当前角度 |

### 3.2 自动瞄准

- 炮台**始终搜索轨道周围最近的敌人**
- 炮管平滑旋转瞄准目标
- 瞄准即开火，无需手动操作
- 没有目标时炮管指向轨道外侧

### 3.3 炮台属性

| 属性 | 初始值 | 说明 |
|------|--------|------|
| `orbitSpeed` | 90°/s | 轨道移动角速度 |
| `detectionRange` | 15 | 索敌半径 |
| `fireRate` | 1.0 | 每秒射击次数 |
| `damage` | 10 | 单发伤害（子弹基础） |
| `bulletCount` | 1 | 每次射击子弹数 |

### 3.4 炮台升级

通过积分在商店购买提升：

| 升级项 | 效果 | 每次购买加成 |
|--------|------|-------------|
| 移动速度 | `orbitSpeed +10%` | +10%/买 |
| 索敌范围 | `detectionRange +2` | +2/买 |
| 射速 | `fireRate +0.2/s` | +0.2/买 |
| 多发射击 | `bulletCount +1` | +1/买 |

## 4. 子弹系统

### 4.1 子弹商店

所有子弹通过积分商店购买，永久拥有，可随时切换。

| 子弹类型 | 价格(积分) | 特点 |
|----------|-----------|------|
| **普通弹** | 初始拥有 | 直线飞行，无穿透，伤害×1.0 |
| **穿透弹** | 500 | 穿透 2 个敌人，伤害×0.8 |
| **追踪弹** | 1000 | 自动追踪最近目标，伤害×1.2 |
| **爆炸弹** | 2000 | 命中触发范围伤害(3m)，伤害×1.5 |
| **散射弹** | 1500 | 每次发射 3 颗扇形子弹，单颗伤害×0.6 |
| **穿甲弹** | 3000 | 穿透 5 个，无视距离衰减，伤害×1.0 |
| **毒液弹** | 4000 | 命中后持续伤害 3 秒，伤害×0.7 |

### 4.2 子弹属性参数

| 参数 | 说明 | 影响 |
|------|------|------|
| `damage` | 单发伤害 | 购买子弹伤害升级 ×1.2/买 |
| `speed` | 飞行速度 | 基础 20，追踪弹较慢 |
| `penetration` | 穿透次数 | 0=击中消失 |
| `isHoming` | 是否追踪 | 追踪弹特有 |
| `splashRadius` | 爆炸范围 | 爆炸弹特有 |
| `dotDuration` | 持续伤害 | 毒液弹特有 |

### 4.3 通用子弹升级

独立于子弹类型，所有子弹共享：

| 升级项 | 每次购买加成 | 最高等级 |
|--------|-------------|---------|
| 伤害强化 | +20% | 10 |
| 速度强化 | +15% | 8 |
| 子弹大小 | +10% | 5 |

## 5. 敌人系统（怪物鱼群）

### 5.1 核心机制

敌人是**使用 boids 群游算法的鱼群怪物**。鱼群在竞技场中自然聚集、分离、巡游，产生动态的战斗体验。部分鱼群会有目标地向玩家轨道靠近。

### 5.2 敌人类型

| 类型 | 血量 | 速度 | 积分 | 行为特征 |
|------|------|------|------|---------|
| **普通鱼(Normal)** | 30 | 2.0 | 10 | 标准 boids 行为，占鱼群主体 |
| **快速鱼(Fast)** | 15 | 5.0 | 25 | 高速巡游，偶尔冲刺靠近轨道 |
| **坦克鱼(Tank)** | 120 | 1.2 | 50 | 大型慢速，吸引子弹保护小鱼 |
| **飞鱼(Flying)** | 40 | 3.5 | 35 | 上下波动飞行，更难瞄准 |

### 5.3 鱼群行为 (Boids 算法)

每条鱼遵循三个规则：

| 规则 | 权重 | 说明 |
|------|------|------|
| **分离 (Separation)** | 1.5 | 避免与邻近鱼碰撞 (距离 < 1.0m) |
| **聚合 (Cohesion)** | 1.0 | 向邻近鱼群中心靠拢 (距离 < 3.0m) |
| **对齐 (Alignment)** | 0.8 | 匹配邻近鱼的平均速度方向 |

额外规则：
- **边界约束**: 超出活动边界时折返向中心
- **目标偏向**: 部分鱼有向轨道靠近的趋势（模拟"攻击"行为）

### 5.4 生成规则

| 参数 | 初始值 | 说明 |
|------|--------|------|
| `totalFishCount` | 30 | 场上总鱼数 |
| `fishCountPerRadius` | +5/级 | 轨道每扩展一级 +5 条 |
| `maxFishCount` | 200 | 场上最多鱼数 |
| `spawnInterval` | 2s | 低于目标数量时的补充间隔 |
| `spawnArea` | 轨道外 3-8m | 生成位置 |

### 5.5 难度曲线

随轨道半径扩展，鱼群逐步升级：

| 轨道半径 | 活跃鱼类型 | 血量倍率 | 积分倍率 |
|----------|-----------|---------|---------|
| 10 | 普通鱼 | ×1.0 | ×1.0 |
| 15 | 普通鱼 + 快速鱼 (20%) | ×1.2 | ×1.1 |
| 22 | 普通鱼 + 快速鱼 + 飞鱼 (10%) | ×1.5 | ×1.2 |
| 30 | 全类型 + 坦克鱼 (10%) | ×2.0 | ×1.4 |
| 40 | 全类型混出 | ×2.8 | ×1.6 |
| 50 | 全类型，血量极限 | ×4.0 | ×2.0 |

## 6. 积分与商店系统

### 6.1 积分获取

| 来源 | 数量 |
|------|------|
| 击杀普通鱼 | 10 × 积分倍率 |
| 击杀快速鱼 | 25 × 积分倍率 |
| 击杀飞鱼 | 35 × 积分倍率 |
| 击杀坦克鱼 | 50 × 积分倍率 |

### 6.2 商店界面

商店在游戏进行中随时可打开（按 Tab），时间不暂停。

```
┌────────────── 商店 ──────────────┐
│ 当前积分: 2,350                  │
│                                  │
│ [穿透弹]           500  ✓已购买  │
│ [追踪弹]          1000  ✓已购买  │
│ [爆炸弹]          2000  [购买]   │
│ [散射弹]          1500  [购买]   │
│ [穿甲弹]          3000  [购买]   │
│ [毒液弹]          4000  [购买]   │
│ ─────────────────────────────── │
│ 伤害强化 Lv.2     +40%  [500]   │
│ 速度强化 Lv.1     +15%  [400]   │
│ 子弹大小 Lv.0     +0%   [300]   │
│ ─────────────────────────────── │
│ 炮台移速 Lv.3     +30%  [600]   │
│ 索敌范围 Lv.1     +2    [400]   │
│ 射速 Lv.2         +0.4  [500]   │
│ 多发射击 Lv.0      1     [800]  │
└──────────────────────────────────┘
```

### 6.3 装备系统

- 已购买的子弹类型可在商店中**切换装备**
- 同一时间只能装备一种子弹
- 切换无消耗，但需要返回商店

### 6.4 积分用途总结

```
击杀鱼群 → 获得积分
              │
              ├── 购买新子弹类型（永久解锁）
              ├── 升级子弹属性（伤害/速度/大小）
              ├── 升级炮台属性（移速/射程/射速/多发射击）
              │
              └── 积分用于购买 → 更强火力 → 击杀更多鱼 → 更多积分 → 良性循环
```

## 7. 游戏流程

### 7.1 单局流程

```
开始
  │
  ▼
轨道半径 10，30条普通鱼，装备普通弹
  │
  ▼
┌──────────────────────────────────────┐
│           核心循环                     │
│                                      │
│  移动炮台 → 射击鱼群 → 获得积分        │
│      │                      │         │
│      │                      ▼         │
│      │              积分够 → 买升级    │
│      │                      │         │
│      ▼                      ▼         │
│  轨道扩大 ←── 分数达标 ←── 战力提升    │
│  鱼群变强                          │   │
│                                      │
└──────────────────────────────────────┘
  │
  ▼
无限循环，追求最高分
```

### 7.2 游戏状态

| 状态 | 说明 |
|------|------|
| `启动` | 直接进入游戏（无主菜单时） |
| `游戏中` | 核心循环，可随时打开商店 |
| `商店` | Tab 切换，游戏不暂停 |

未来扩展：
- `主菜单`: 开始/设置
- `暂停`: ESC 暂停
- `结算`: 当前积分、击杀统计

### 7.3 积分阈值触发事件

| 积分 | 事件 |
|------|------|
| 100 | 首次轨道扩展提示 |
| 500 | 轨道半径 → 15，鱼群 +10，快速鱼出现 |

| 1500 | 轨道半径 → 22，飞鱼出现 |
| 2000 | 爆炸弹解锁可见 |
| 3500 | 轨道半径 → 30，坦克鱼出现 |
| 5000 | 穿甲弹解锁可见 |
| 7000 | 轨道半径 → 40 |
| 10000 | 毒液弹解锁可见 |
| 12000 | 轨道半径 → 50 (最大) |

## 8. 视觉与反馈设计

### 8.1 轨道视觉

- 轨道显示为发光圆环（半透明材质）
- 轨道扩展时播放缩放动画 + 粒子爆发效果
- 玩家炮台在轨道上有一个高亮指示点

### 8.2 战斗反馈

| 事件 | 视觉反馈 | 音频 |
|------|---------|------|
| 击中敌人 | 敌人闪白 + 血迹粒子 | 命中音效 |
| 击杀敌人 | 爆炸粒子 + 积分飘字 | 击杀音效 |
| 轨道扩展 | 圆环脉冲扩散 + 全屏闪 | 升级音效 |
| 购买升级 | 炮台闪光 | UI音效 |
| 切换子弹 | 子弹变色特效 | 切换音效 |

### 8.3 鱼群视觉

- 不同类型使用不同颜色/大小区分
- 鱼群密度高处水面有泡沫粒子
- 受伤的鱼颜色变暗

## 9. 技术概述

### 9.1 复用现有系统

| 现有系统 | 在新设计中的用途 |
|----------|-----------------|
| `Turret.cs` | 炮台核心（瞄准、射击、对象池） |
| `Bullet.cs` + `BulletConfig` | 子弹系统（新增多种子弹类型） |
| `EnemyBase.cs` + 变体 | 敌人鱼（需要调整为鱼群行为） |
| `Flocking/` | 鱼群群游（计划 ECS 优化） |
| `SurfaceMovement` (Plane 模式) | 炮台在轨道上的圆形约束移动 |
| `ResourceManager` | 积分系统 |
| `ObjectPool` | 子弹、特效、鱼对象池 |
| `EffectManager` | 战斗特效 |
| `AudioManager` | 音效播放 |

### 9.2 需要新增

| 新系统 | 说明 |
|--------|------|
| `OrbitConstraint` | 约束炮台在圆形轨道上移动 |
| `ScoreManager` | 积分累计、阈值检测、事件触发 |
| `ShopManager` | 购买逻辑、子弹解锁、装备切换 |
| `ArenaManager` | 轨道半径管理、鱼群数量控制 |
| UI 系统 | HUD、商店界面、积分飘字 |

### 9.3 数据流

```
ArenaManager (轨道半径、鱼群数量)
      │
      ▼
EnemySpawnManager → 鱼群 Entity/MonoBehaviour
      │
      ▼
Turret → 索敌 → 开火 → Bullet → 碰撞 → 鱼 TakeDamage
      │                                      │
      ▼                                      ▼
OrbitConstraint                        ScoreManager (积分+)
      │                                      │
      ▼                                      ▼
玩家输入 ←──── 积分阈值检测 ─────────── ArenaManager (扩展轨道)
                                           │
                                           ▼
                                    ShopManager (购买)
```

## 10. 数字平衡总表

### 10.1 初始状态

| 参数 | 值 |
|------|-----|
| 轨道半径 | 10 |
| 鱼群数量 | 30 |
| 鱼类型 | 仅普通鱼 |
| 子弹类型 | 普通弹 |
| 子弹伤害 | 10 |
| 射速 | 1/s |
| 索敌范围 | 15 |
| 移动速度 | 90°/s |

### 10.2 满级状态

| 参数 | 值 |
|------|-----|
| 轨道半径 | 50 |
| 鱼群数量 | 200 |
| 鱼类型 | 全部混出 |
| 鱼血量倍率 | ×4.0 |
| 积分倍率 | ×2.0 |
| 最高子弹伤害 | ~60 (满级穿甲弹) |
| 最高射速 | ~3/s |

### 10.3 设计原则

- **击杀时间 (TTK)**: 普通鱼在玩家同级子弹下 3-5 秒击杀
- **积分获取率**: 初始约 100/分钟，后期约 600/分钟
- **升级节奏**: 每 2-3 分钟可以买一次新升级
- **轨道扩展**: 每约 5-8 分钟触发一次
