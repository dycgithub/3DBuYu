# 3DBuYu (3D捕鱼) 游戏设计文档

**版本**: 3.0
**日期**: 2026-05-06
**引擎**: Unity 2022.3.13f1c1 (LTS)
**渲染管线**: URP 14.0.9

---

## 1. 游戏概述

### 1.1 核心概念

3DBuYu 是一款**球面世界射击游戏**，融合三种玩法基因：

| 灵感来源 | 借鉴机制 |
|----------|---------|
| **捕鱼游戏** | 资源管理（射击=消耗）、抽奖特效 |
| **黄金矿工** | 单局限时、商店购物 |
| **原创设计** | 球面移动、自动索敌炮台、Buff机制 |

玩家控制炮台在**球体表面**移动，自动瞄准并攻击球体内部的怪物鱼群。基础子弹免费发射，高级子弹消耗分数。每局限时，时间到检查分数是否达标——达标晋级，未达标失败。

### 1.2 一句话描述

> 在球面上移动炮台，自动索敌射击球内鱼群，管理分数资源，限时达标晋级。

### 1.3 独特卖点

- **球面世界**: 炮台在球体表面移动，鱼群在球内空间游动，利用 boids 算法产生自然群游行为
- **分数=资源**: 分数既是积分也是弹药货币——基础弹免费，高级弹消耗分数，打中回本，打空亏分
- **限时压力**: 每局倒计时，分数门槛递进，时间管理+射击效率双重考验
- **Buff叠加**: 商店购买常驻Buff + 击杀掉落临时Buff，叠加爆发
- **捕鱼抽奖**: 击杀特效华丽，特殊鱼种触发抽奖轮盘

### 1.4 核心游戏循环

```
球面移动炮台(键盘 WASD)
        │
        ▼
自动索敌 ──→ 射击球内鱼群
  │                │
  │                ├── 基础弹(免费) → 命中得分
  │                └── 高级弹(消耗分数) → 命中高回报
  │
  ▼
击杀得分 + 掉落Buff道具(临时)
  │
  ▼
打开商店(Tab) ──→ 用分数购买
  │                ├── 新子弹类型(永久解锁)
  │                ├── 子弹/炮台升级
  │                └── 常驻Buff
  │
  ▼
倒计时结束 ──→ 分数 ≥ 门槛 ?
  ├── 是 → 关卡晋级，难度提升
  └── 否 → 游戏结束
```

### 1.5 游戏结束条件

- **失败**: 单局倒计时结束，总分未达到门槛分数
- **胜利**: 通过所有关卡（暂定 10 关）或无限模式追求高分
- 炮台不受伤害，无死亡机制

## 2. 球面世界设计

### 2.1 基本结构

```
              ┌─────────────────────┐
              │    球体外壳(表面)    │
              │  ┌───────────────┐  │
              │  │  球体内部空间  │  │
              │  │              │  │
              │  │   🐟🐟🐟    │  │  ← 鱼群在球内游动
              │  │   🐟  🐟    │  │
              │  │    🐟🐟     │  │
              │  │              │  │
              │  └───────────────┘  │
              │       ▲ 炮台       │  ← 玩家在球面上移动炮台
              └─────────────────────┘
```

- **球体外壳**: 玩家炮台在球体表面移动（使用球面移动系统）
- **球体内部**: 鱼群在球内三维空间游动（使用 boids 算法）
- **炮台朝向**: 始终指向球心，瞄准球内鱼群
- **球体可视化**: 半透明外壳 + 经纬线框，让玩家能看到内部鱼群

### 2.2 球体参数

| 参数 | 初始值 | 说明 |
|------|--------|------|
| `sphereRadius` | 10.0 | 球体半径 |
| `minRadius` | 5.0 | 最小球体半径 |
| `maxRadius` | 30.0 | 最大球体半径 |
| `visualTransparency` | 0.3 | 球壳透明度 |

### 2.3 球体扩展

球体半径随关卡增长（不是分数），让鱼群有更大的活动空间：

| 关卡 | 球体半径 | 说明 |
|------|----------|------|
| 1 | 10 | 小球，鱼群密度高，容易命中 |
| 2 | 12 | 鱼群空间稍大 |
| 3 | 15 | 鱼种类增加 |
| 4 | 18 | 出现快速鱼 |
| 5 | 22 | 出现坦克鱼 |
| 6-10 | 25-30 | 全鱼种混出，难度极限 |

## 3. 炮台系统

### 3.1 基本机制

炮台是玩家的唯一操控对象，附着在球体表面，不受伤害。

| 操作 | 按键 | 说明 |
|------|------|------|
| 球面移动 | WASD | 在球体表面沿经纬线方向移动 |
| 打开商店 | Tab | 游戏不暂停 |
| 切换子弹 | 1-5 数字键 | 快速切换已购买的子弹类型 |

### 3.2 自动瞄准

- 炮台**始终搜索球内最近的敌人**
- 炮管平滑旋转瞄准目标（穿透球壳指向内部）
- 瞄准即自动开火（基础弹），高级弹需手动切换
- 没有目标时炮管指向球心默认方向

### 3.3 炮台属性

| 属性 | 初始值 | 说明 |
|------|--------|------|
| `moveSpeed` | 30°/s | 球面移动角速度 |
| `detectionRange` | 球半径+5 | 索敌范围（穿透球壳） |
| `fireRate` | 1.0/s | 每秒射击次数（基础弹） |
| `damage` | 10 | 单发伤害 |
| `bulletCount` | 1 | 每次射击子弹数 |

### 3.4 炮台升级（商店购买）

| 升级项 | 效果 | 每级加成 | 价格递增 |
|--------|------|---------|---------|
| 移动速度 | `moveSpeed +10%` | +10%/级 | 200→400→800... |
| 索敌范围 | `detectionRange +2` | +2/级 | 150→300→600... |
| 射速 | `fireRate +0.2/s` | +0.2/级 | 300→600→1200... |
| 多发射击 | `bulletCount +1` | +1/级 | 500→1000→2000... |

## 4. 子弹系统

### 4.1 子弹=分数消耗

| 子弹类型 | 基础消耗(分/发) | 特点 |
|----------|:---:|------|
| **普通弹** | 0 | 直线飞行，无穿透，伤害×1.0，初始拥有 |
| **穿透弹** | 5 | 穿透 3 个敌人，伤害×0.8 |
| **追踪弹** | 8 | 自动追踪最近目标，伤害×1.2 |
| **爆炸弹** | 15 | 命中触发范围伤害(2m)，伤害×1.5 |
| **散射弹** | 10 | 每次发射 3 颗扇形子弹，单颗伤害×0.6 |
| **穿甲弹** | 20 | 穿透 5 个，无视距离衰减，伤害×1.0 |
| **毒液弹** | 12 | 命中后持续伤害 3 秒，伤害×0.7 |

**消耗规则**:
- 切换高级弹后，每发射一发扣除对应分数
- 分数不足时自动切换回普通弹
- 命中敌人获得的基础分 + 额外奖励分 > 子弹消耗（设计保证正收益）

### 4.2 子弹商店

| 子弹类型 | 解锁价格(分) | 说明 |
|----------|:---:|------|
| **普通弹** | 初始拥有 | 免费无限使用 |
| **穿透弹** | 500 | 永久解锁，使用消耗5分/发 |
| **追踪弹** | 1000 | 永久解锁，使用消耗8分/发 |
| **散射弹** | 1500 | 永久解锁，使用消耗10分/发 |
| **爆炸弹** | 2000 | 永久解锁，使用消耗15分/发 |
| **毒液弹** | 3000 | 永久解锁，使用消耗12分/发 |
| **穿甲弹** | 5000 | 永久解锁，使用消耗20分/发 |

### 4.3 通用子弹升级

独立于子弹类型，所有子弹共享：

| 升级项 | 每级加成 | 最高等级 | 价格递增 |
|--------|---------|:---:|---------|
| 伤害强化 | +20% | 10 | 400→800→1600... |
| 速度强化 | +15% | 8 | 300→600→1200... |
| 子弹大小 | +10% | 5 | 200→400→800... |

## 5. 敌人系统（球内鱼群）

### 5.1 核心机制

敌人是**在球体内部游动的怪物鱼群**，使用 boids 群游算法产生自然行为。鱼群在球内三维空间自由游动，部分鱼会主动靠近球壳（炮台方向）。

### 5.2 敌人类型

| 类型 | 血量 | 速度 | 击杀分 | 行为特征 |
|------|------|------|:---:|---------|
| **普通鱼** | 30 | 2.0 | 10 | 标准 boids 行为，鱼群主体 |
| **快速鱼** | 15 | 5.0 | 25 | 高速巡游，偶尔冲刺靠近球壳 |
| **坦克鱼** | 120 | 1.2 | 50 | 大型慢速，吸引火力保护小鱼 |
| **飞鱼** | 40 | 3.5 | 35 | 上下波动飞行，更难瞄准 |
| **黄金鱼** | 80 | 2.5 | 200 | 稀有出现，击杀触发抽奖轮盘 |
| **BOSS鱼** | 500 | 1.0 | 1000 | 关卡BOSS，巨大体型，特殊攻击模式 |

### 5.3 鱼群行为 (Boids 算法)

每条鱼遵循三个核心规则：

| 规则 | 权重 | 说明 |
|------|------|------|
| **分离 (Separation)** | 1.5 | 避免与邻近鱼碰撞 (距离 < 1.0m) |
| **聚合 (Cohesion)** | 1.0 | 向邻近鱼群中心靠拢 (距离 < 3.0m) |
| **对齐 (Alignment)** | 0.8 | 匹配邻近鱼的平均速度方向 |

额外规则：
- **球内约束**: 超出球体半径时折返向球心
- **炮台趋向**: 15% 的鱼在炮台附近游动（易于射击）
- **BOSS光环**: BOSS鱼周围聚集保护性小鱼

### 5.4 生成规则

| 参数 | 初始值 | 说明 |
|------|--------|------|
| `totalFishCount` | 25 | 场上总鱼数 |
| `fishCountPerLevel` | +5/关 | 每关 +5 条 |
| `maxFishCount` | 150 | 场上最多鱼数 |
| `spawnInterval` | 3s | 低于目标数量时的补充间隔 |
| `goldenFishRate` | 3% | 黄金鱼出现概率 |
| `bossLevels` | 5, 10 | BOSS关 |

### 5.5 难度曲线

| 关卡 | 活跃鱼类型 | 血量倍率 | 积分倍率 |
|:---:|-----------|:---:|:---:|
| 1 | 普通鱼 | ×1.0 | ×1.0 |
| 2 | 普通鱼 + 快速鱼(15%) | ×1.2 | ×1.1 |
| 3 | 普通鱼 + 快速鱼 + 飞鱼(10%) | ×1.5 | ×1.2 |
| 4 | 全类型 + 坦克鱼(10%) | ×2.0 | ×1.4 |
| 5 | BOSS关 | ×2.5 | ×1.5 |
| 6-9 | 全类型混出 | ×2.8→4.0 | ×1.6→2.0 |
| 10 | 最终BOSS | ×5.0 | ×3.0 |

## 7. Buff 系统

### 7.1 Buff 类型

| Buff | 效果 | 持续时间 | 来源 |
|------|------|:---:|------|
| **穿透** | 子弹穿透数+2 | 15s | 掉落/商店 |
| **加时间** | 限时+30秒 | 即时 | 掉落/商店 |
| **双倍得分** | 所有得分×2 | 20s | 掉落/商店 |
| **射速提升** | 射速×1.5 | 20s | 掉落 |

## 10. 游戏流程

### 10.1 单关流程

```
关卡开始
  │
  ├── 倒计时启动（120-360秒，随关卡递增）
  ├── 鱼群生成（数量随关卡递增）
  ├── 玩家起始分数 = 0
  │
  ▼
┌────────────────────────────────────────┐
│              核心循环                    │
│                                        │
│  WASD移动炮台 → 自动瞄准射击 → 击杀得分  │
│       │              │            │     │
│       │              ▼            ▼     │
│       │        高级弹扣分    掉落Buff    │
│       │              │            │     │
│       ▼              ▼            ▼     │
│  Tab商店(不暂停) ← 分数资源管理          │
│                                        │
└────────────────────────────────────────┘
  │
  ▼
倒计时归零
  │
  ├── 分数 ≥ 门槛 → 通关！进入商店休整 → 下一关
  └── 分数 < 门槛 → 失败 → 显示结算 → 重新挑战
```

### 10.2 游戏状态

| 状态 | 说明 |
|------|------|
| `主菜单` | 开始游戏 / 设置 / 排行榜 |
| `游戏中` | 核心循环，Tab 打开商店（不暂停） |
| `商店` | Tab 切换，时间继续流逝 |
| `抽奖` | 击杀黄金鱼触发，时间暂停 |
| `通关结算` | 显示分数、评级、解锁内容 |
| `失败结算` | 显示分数、差多少达标 |

### 10.3 关卡事件

| 关卡 | 事件 |
|:---:|------|
| 1 | 教程提示：移动、射击、商店 |
| 2 | 快速鱼出现 |
| 3 | 飞鱼出现 |

### 11.3 设计原则

- **单关时长**: 2-6 分钟，节奏紧凑
- **基础TTK**: 普通鱼在普通弹下 3-4 发击杀（3-4秒）
- **分数净收益**: 高级弹命中敌人 → 得分 > 子弹消耗，保底收益+20%
- **商店频率**: 每关可购买 1-3 次升级
- **Buff覆盖率**: 临时Buff覆盖约 20-30% 的游戏时间
